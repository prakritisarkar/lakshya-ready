# Lakshya Ready

> Practice. Improve. Get Interview Ready.

AI-powered voice-based mock interview platform for CS students.

## Tech Stack

* Next.js 14 (App Router)
* TypeScript
* Tailwind CSS
* Firebase
* Gemini API
* Web Speech API
* Recharts
* Vercel

## Features

* Voice-based AI interviews
* Role-specific tracks (SDE, Frontend, Python, Data Analyst, ML)
* Growth dashboard with score tracking
* Resume Reality Check
* AI-generated study roadmaps
* Candidate memory system

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000
